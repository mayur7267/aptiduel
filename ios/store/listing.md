## App Review notes

```
No sign-in is needed to review the app: it creates a guest account on first launch. Quick Match, the Daily Challenge, company practice, the leaderboards and the profile all work as a guest.

"Duel a friend" (live duels) asks for an email address: the app sends a one-time code to that address to save the account. Everything else works without it. Players can delete their account in Profile > Account > Delete account.

Practice opponents marked "Bot" are computer players. Company names appear only to say which topics a practice set covers; the app is independent and says so in its description.
```

## App Privacy ("nutrition label") answers

Nothing is used for tracking and nothing is shared with advertisers. Everything
below is collected, linked to the player's account, for App Functionality
(Gameplay content also for Analytics). This matches `Apticks/Resources/PrivacyInfo.xcprivacy`.

| Data type | Why |
|---|---|
| Contact Info › Email Address | Only if the player saves their account (one-time sign-in codes) |
| Contact Info › Name | The display name on leaderboards and in duels |
| Identifiers › User ID | The random ID of the guest or saved account |
| User Content › Gameplay Content | Duels, answers, scores, rating, streaks |
| User Content › Other User Content | Feedback messages the player sends |
| Other Data › Other Data Types | College, graduation year, test countdown |
| Diagnostics › Other Diagnostic Data | App version and device model, sent only with feedback |

Not collected: location, contacts, photos, health, financial data, browsing or
search history, purchases, advertising identifier.
